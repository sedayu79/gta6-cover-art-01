# Vice Nights — GTA 6 Cover Art Maker

Turn your photos and a caption into GTA 6-style cover art. A static web app: load photos, crop and position them across panels, write a bold caption, and export the poster as a PNG in 1080x1080, 1080x1350 or 1920x1080.

## Run it

Open `app/index.html` in a desktop browser, or serve the `app/` folder with any static server. No build step, no network needed at runtime.
